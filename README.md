# 🐣 弹射怪兽 · 弹弓物理射击

一个**纯前端**的物理弹弓小游戏：拖住小怪兽往后拉，松手弹射，击倒结构、消灭所有目标。
原生 **Canvas 2D + Matter.js**，无框架、无构建、无打包，双击 `index.html` 即玩。

> 100 关 · 6 款皮肤（各带被动与主动技能）· 5 套场景主题 · 弹药制星级评分

## 🌐 在线体验

**https://monster-slingshot.app.workbuddy.host/**

手机、平板、电脑浏览器直接打开即可玩，无需安装。

## 🎮 玩法

1. **拖拽瞄准**：按住弹弓上的小怪兽往后拉，屏幕上会实时画出**预测抛物线**——这条线与真实飞行同参数（推进加速 + 空气阻力 + 三面墙反弹 + 落地弹跳），弧线尽头的红色准星就是预测落点。
2. **松手发射**：力度由拉弓距离决定（最多 105px），初速 30 起、沿速度方向推进至 35。
3. **击倒结构**：木块 / 冰块 / 石墙有各自硬度，倒塌时触发物理爆炸；冰块一碰就碎，石墙后 50 关明显加固。
4. **消灭目标**：关掉全部小怪兽即通关；结构砸中、爆炸波及、小鸟直接撞击都算。
5. **小炸弹**（第 31 关起）：结构顶部会放炸弹，被小鸟**直接撞到即爆炸判负**；失去支撑落地则安全消失。
6. **主动技能**：飞行中按 `空格` 或点一下屏幕，触发当前皮肤的技能。

**评分按剩余弹药**：剩 ≥2 发 = ★★★，剩 1 发 = ★★☆，最后一发惊险通关也保底 ★☆☆。

## 🐍 100 关与难度爬坡

难度不是分段跳变，而是**随关卡连续叠加**（第 1 关 → 第 100 关）：

| 难度要素 | 第 11 关 | 第 100 关 |
|---|---|---|
| 石头占比 | 18% | 88% |
| 塔楼高度 | 70px | 94px |
| 塔二层 / 金字塔加层 / 碉堡护顶概率 | 42% / 20% / 15% | 77% / 75% / 70% |
| 出现 3 组结构的概率 | 25% | 70% |
| 石墙硬度 HP（31 关起线性上涨） | 120 | 168 |
| 炸弹出现率（31 关起） | 30% | 60%（63 关起上限 3 颗 + 双保底） |

段位名平滑过渡：11-35 进阶 → 36-61 困难 → 62-88 专家 → 89-100 地狱。
前 10 关为手工设计，第 11 关起由确定性随机数生成器（mulberry32）产出——**同一关卡每次进来的结构完全一致**。

## 🧬 皮肤与技能

绿色小蛙（朴素建模）为初始皮肤；每 15 关随机解锁一款（15 / 30 / 45 / 60 / 75）。

| 皮肤 | 被动 | 主动（空格 / 点击） |
|---|---|---|
| 🐸 小蛙 | 均衡 | 无 |
| 👾 橙橙怪兽 | 分身强化 | **分身**：一分为二，两个方向错开飞 |
| 🐤 小鸡 | 爆炸范围最大（230） | **空中引爆**：半空引爆本发，落地不再炸 |
| 😈 焰焰恶魔 | 爆炸威力高、范围小 | **空中引爆 + 隔空引爆炸弹**（不判负） |
| 🧊 冰冰蓝怪 | 爆炸直接炸伤方块（碎石） | **空中引爆 + 碎石**（石墙也能炸） |
| 🦄 独角兽 | 穿甲 ×2.5 | **冲刺**：速度 ×1.5（上限 42），每发一次 |

## 🐛 踩过的坑（已修复）

1. **弹不出去**：Matter.js 的 `setStatic` 创建后 `setStatic(false)` 质量不还原（保持 `Infinity`），位置直接变 `NaN`。
   修法：瞄准阶段纯 JS 记录 `aimPos` 不建刚体，**发射瞬间**才创建动态刚体并 `setVelocity`。
2. **点「再玩一次」自动通关**：重开后上一局的 700ms 结算定时器仍会触发。
   修法：`roundId` 回合编号 + 定时器句柄 + `win()/lose()` 状态守卫。
3. **第 11 关起闪退**：`LEVELS[idx]` 写死，生成关在数组里不存在。
   修法：`LEVELS[idx] || getLevel(idx)`，100 关全量建局测试通过。
4. **第 10 关通关后卡死**：关卡总数从 10 升到 100 时，三处仍用 `LEVELS.length`（判解锁 / 按钮显隐 / 跳转上限）。
   修法：统一 `TOTAL_LEVELS` + 存档自愈（按已有星级反推解锁进度取 `max`）。
5. **静态墙反弹失效**：Matter 0.19/0.20 的静态墙 `restitution` 实测不生效（反弹系数恒 ~0.33）。
   修法：在 `collisionStart` 回调里用**求解前速度**手动做镜面反射（法向反转 ×0.95）。
6. **推进力被空气阻力吃掉**：`BOOST_RATE = 0.07` 时速度在 30 附近就上不去了（阻力约 0.18/帧）。
   修法：提到 0.28，实现初速 30 → 末速 35 的加速手感。
7. **抛物线预览"看着准其实不准"**：预览只算初速 + 重力，实际还有推进、阻力与反弹，越到后面偏得越多（满力撞墙弹回偏差 1272px）。
   修法：预览逐帧模拟与真实飞行**完全同参数**，偏差降到 13~67px，并加落点标记与弹跳预测。
8. **测试假阳性**：早先用大跨度时间戳（250ms）驱动循环，会一次性跨过所有计时阈值，把"累加器写错导致物体不动"这类缺陷放过。自测统一改为**真实 60fps 细帧（16.7ms/帧）**驱动。

## 🚀 本地运行

直接双击 `index.html` 即可，无需依赖、无需服务器（物理引擎已内置在 `vendor/`）。

## ✅ 自测

零依赖冒烟测试，只用 Node 内置模块：

```
node test_smoke.js
```

它用 `vm` + 手写桩 DOM 在无浏览器环境下真实加载 `script.js`（含内置 Matter），**故意让 `localStorage` 抛 `SecurityError`** 复现沙箱场景，逐项验证 53 条：

- 语法与文件引用完整性；脚本在沙箱环境完整加载不崩
- `load` 启动流程：菜单渲染出 100 个关卡格子与皮肤卡片
- 90 个程序生成关结构合规（不越界、刚体数不超限、31 关前无炸弹）、石头占比随关卡上升
- 石墙 HP 爬坡（31 关 ≈120 → 100 关 ≈168）
- 场景主题按关卡段轮换、5 套主题字段完整
- 星级 = 剩余弹药（0 / 1 / ≥2 发 → 1 / 2 / 3 星）
- 发射链路：按下抓取 → 拖动 → 松手 → 真实物理推进（细帧驱动，逐帧采样轨迹 / 检查 NaN / 零异常帧）
- 主动技能空格触发分身、同一发不重复触发
- 胜负判定（延时结算判胜、弹尽判负、状态守卫不重复判定、重开新局正常）

> 隔离环境跑不了浏览器时，这是"游戏是否真的能玩"的最低成本保险。

## ☁️ 部署

纯静态站点，任意静态托管都行：

**方式一 · Vercel（推荐）**

```bash
git init
git add .
git commit -m "feat: 弹射怪兽 弹弓物理射击"
git branch -M main
git remote add origin https://github.com/<你的用户名>/monster-slingshot.git
git push -u origin main
```

打开 [vercel.com](https://vercel.com) → GitHub 登录 → **Add New Project** → 导入仓库 → Framework Preset 选 `Other` → Deploy。

**方式二 · GitHub Pages**：仓库 Settings → Pages → Source 选 `main` 分支根目录即可。
